# Country Data Analysis

Exploratory analysis of country data using Python and Pandas.

## Analysis Performed

1. Identified the country with the highest population.
2. Found the capital of the most populated country.
3. Identified the country with the least population.
4. Found the capital of the least populated country.
5. Found the top 5 countries with the highest democratic scores.
6. Calculated the total number of regions.
7. Counted the countries located in Eastern Europe.
8. Identified the political leader of the second-highest populated country.
9. Counted the countries whose political leader is unknown.
10. Counted the countries with "Republic" in their full name.
11. Identified the most populated country in the African region.

## Tools Used

- Python
- Pandas
- Jupyter Notebook

## Dataset

The dataset contains information about countries, including population, capitals, regions, political leaders, country names, and democratic scores.
